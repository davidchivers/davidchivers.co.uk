City size requires a consistent definition of the city

19 October 2026. Public population-reference construction and a separate approved 2019 final-file geography audit. This advances the larger-city question in note 93; it is not a new regression or a test of attitudes.

Bottom line

We now have a checked population denominator for 2017-2019, on one explicit metropolitan definition. We should not simply merge it to an old MSA code and assume the geography is identical.

The common-reference choice is September 2018 OMB delineations, with Vintage 2019 Census population estimates for July 1 of each study year. That provides 384 metropolitan and 542 micropolitan areas in the 50 states plus DC. The proposed city-size analysis uses metros, not all CBSAs. A CBSA can be either metro or micro; neither a venue count nor an arbitrary recorded MSA code is a population measure. Puerto Rico is outside this particular population source.

What to do with this

  1. Use the common public reference as a candidate, not an automatic merge. Keep metro/micro classification, population year and boundary vintage explicit. Resolve the recorded-geography convention before an inference sample is fixed. Retain a flow diagram of all exclusions.
  2. Ask the producer for the actual geography assignment step. We need its dated delineation/crosswalk, the meanings of MSA_CODE and destination_county, and the handling of non-CBSA/unmatched areas. A known code is not enough, and choosing the vintage with the highest match rate would not establish provenance. This is part of the original replication request, not a request to rerun everything blindly.
  3. Then reconstruct the income-group masses and run the planned split. The file-to-file adapter has passed artificial tests, but its annual-flow and ACS-lookup approval is still pending. A population lookup cannot replace group-by-venue masses. County subdivisions remain too coarse to identify a shared shopping centre or a genuine feasible menu.

The economic question remains: does separation in larger cities occur across service types, across destination areas, or between establishments within an area and service type? The present work strengthens the denominator and merge checks needed to ask it. It does not answer which component dominates, establish preferences for co-patrons, or show that adding venues causes sorting.
