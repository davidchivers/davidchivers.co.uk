Main conclusion

Do not combine the two public NYPL 1947 derivatives or choose the larger one as a verified historical sampling frame. They overlap substantially, but each contains source-image regions absent from the other; shared entries also differ in city, category and coordinate fields. This resolves the earlier uncertainty about whether the 796-row file is simply a subset of the 1,056-row file under the inspected exact source-region key. It does not resolve why the versions diverged, which transcription is correct or whether either covers a complete edition.

The Green Book direction remains narrowed to an outcome-blind historical site feasibility study, separate from the main contemporary-mixing paper. The North Carolina inventory remains the strongest bounded lead, conditional on obtaining its master spreadsheet, exact reuse terms and dated histories. Neither NYPL derivative contains North Carolina-labelled entries. No modern POIs were accessed or matched in this audit.

What was compared

The first source is the 1947 GeoJSON in NYPL’s greenbooks repository. The second is the 1947 GeoJSON supplied with its separate greenbook-map interface; that file has 797 entries, of which one is null. The third is the 796-row display JSON produced for that interface. The repositories describe an experimental interface and OCR/Scribe corrections, not a harmonized longitudinal establishment panel. Both inspected structured-data repositories carry CC0 licences. This audit does not extend that statement to all linked images or to the separate NC map layer. NYPL text/data repository; NYPL map repository.

All three files were fetched at the previously recorded commits and matched their earlier SHA-256 hashes. They were parsed in local process memory only. No listing, name, address, coordinate, source-region identifier or row-level match file was saved or transmitted. The public outputs are aggregate checks.

The exact name/address/city/state/year key excludes missing components and does not expand abbreviations or remove punctuation. Nine entries in the larger source and eight in the map source lack a complete key; the larger source also has one duplicated text key spanning two rows. Duplicate groups are not joined many-to-many. The 528 text pairs agree with the source-region pairs, but this agreement still does not establish historical business identity or continuity.

Category differences are not entirely cosmetic. All 672 shared source-region entries have different raw category strings; 651 remain different after case/whitespace normalization. Applying the inspected parser’s category rules to both sides yields disjoint possible output sets for 179 pairs. This is a coding-version diagnostic, not evidence that establishments changed service type. We have not checked the original page images to decide which category or location is correct.

State counts also differ non-uniformly. California has 154 versus 74 entries, whereas Mississippi has 127 versus 161. Therefore a uniform scaling factor cannot reconcile these source frames. These are derivative counts, not estimates of historical business prevalence or discriminatory access.

Can the map’s display conversion be reproduced?

The map-source file uses the misspelled key geomotry; the inspected Python 2 converter explicitly expects that spelling. Feeding the other GeoJSON to that literal predicate would reject all 1,056 features. That is a schema compatibility issue, not an explanation of the two historical frames. Pinned converter.

For the map’s own input, all seven non-category fields agree with the display file in the same 796-row order, including the longitude/latitude reversal. The 790 unambiguous category rows reproduce exactly as a multiset. Six category strings match more than one substring rule in the original Python 2 dictionary. Each displayed category is compatible with the applicable rules, but the original dictionary order was not verified. We therefore report row-wise compatibility, not exact deterministic reproduction of all 796 category assignments. No downloaded script was executed.

What this changes for the research design

  1. Keep historical coverage separate from modern survival. An absent row in one derivative is not a business closure. Nonlisting is not evidence of discrimination, and a listed business need not have had a mixed crowd.
  2. Do not snap uncertain historical coordinates to the nearest modern POI. First resolve original edition/page evidence and address changes. A shared source-image region is not an address-validated parcel or persistent firm.
  3. Obtain the NC inventory before choosing a pilot denominator. Retain demolished and unknown sites, distinguish firms from sites, and seek dated 2017-2019 operating states. The previously inspected 2024 status labels cannot supply these histories. The earlier 317-resource versus 327-business discrepancy remains unresolved.
  4. Keep the ranking unchanged. This is useful feasibility evidence and a reason to avoid a quick national merge, not a new publication result. The main project still needs the upstream construction audit and Eren’s separately authorized category/area/venue decomposition.

No access request, colleague message, NC feature download, source-image review, new restricted-file read, linkage or regression was undertaken here. The earlier historical and causal-design gates remain binding.

Reproducibility and corrections

The prospective protocol fixes the match keys, distance bands and output scope. The first pass exposed a state-label reporting bug: full state names were placed in the residual group by an abbreviation-only lookup. The corrected lookup recognizes all 50 states and DC and leaves unknown labels explicit. The original receipt and code snapshot are retained. A separate dated addendum records that repair and the post-result category-compatibility diagnostic; it does not change the matching rules.

The corrected comparison and a fresh rerun took 0.60 and 0.74 seconds. All deterministic results, input identities, supporting-source identities and local code/protocol hashes agree. The 26 current synthetic tests cover duplicate multiplicities, incomplete keys, Unicode, ambiguous categories, state labels, coordinate order, distance boundaries and normalized category diagnostics. Independent review and actual delivery are recorded separately, not inferred from this note.

This note supersedes only the earlier claim that the relation between the two 1947 derivatives had not been tested. It preserves the prior source inventory, literature assessment, NC rights/history gaps and original protocols. Published documents and Project sources are snapshots, not live data access.
