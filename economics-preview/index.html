For discussion

A starting point for our community.

This prototype explores an Economics community homepage with direct student links, seminars and a student-life feature. It is hosted separately from the existing Durham website.

Course links lead to published Durham information. The seminar programme opens the dedicated seminar homepage. The Instagram link opens the existing @thedurhamstudent account; an Economics account has not launched. The student photograph illustrates the layout and is not an embedded Instagram post.

The existing Introduction to Economics course is unchanged. A new hub’s publishing scope, branding and ownership would need to be agreed before launch.

No analytics, social-media embeds, sign-up forms or tracking scripts have been added. Photos and identity assets: Durham University. View sources and design notes.
