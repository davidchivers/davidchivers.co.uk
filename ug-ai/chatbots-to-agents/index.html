What we’ll cover

  • See the difference between a chatbot answering a question and an agent working on files.
  • Use a small synthetic dataset to create a chart, then inspect the labels and numbers.
  • Turn a useful procedure into a skill and try it on a second example.

Try it

Inspect before you run

Download the small practice CSV. It contains invented study-hour and quiz-score pairs, not student records. Open it in a course folder and ask your coding assistant to describe its plan before making a chart. Check all six points against the file. A pattern in these invented data is not evidence of a causal effect.

Download practice CSV ↓
Read study_practice.csv and describe the columns. Propose a simple scatter plot of study hours and quiz score. Explain the steps before editing files or running commands, and wait for me to review the plan. Label the chart as synthetic teaching data. Do not interpret the association as causal.
