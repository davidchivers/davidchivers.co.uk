1

Get student access

  1. Create a GitHub account or use your existing one.
  2. Add and verify your university email in Settings → Emails.
  3. Apply for GitHub Education as a student. Follow the prompts for proof of enrolment.
Apply for student access ↗

While you wait, install VS Code and open a folder below.

2

Activate Copilot

Once approved, open Education benefits, find the Copilot benefit and follow the activation prompts.

Check Copilot is active ↗

Only paid options? Wait a few days and retry. You do not need to buy a plan.

3

Install VS Code

Download the version for your laptop, install it and open the app.

Download VS Code ↗
Installation help

Windows: run the downloaded installer and follow the prompts.

Mac: open the downloaded archive, move Visual Studio Code to Applications, then open it.

Choose Visual Studio Code, not Visual Studio. If your laptop blocks installation, use your institution's software portal or ask IT.

4

Sign in to Copilot

  1. In VS Code, select the Copilot icon → Use AI Features (or Sign in to use Copilot).
  2. Sign in with the same GitHub account you used above.
  3. Let the browser return to VS Code, then open Copilot chat.
Cannot find Copilot?

Try VS Code's Accounts menu → Sign in with GitHub to use GitHub Copilot. If it is missing, update VS Code and follow the official setup guide.

5

Open a project folder

Create an empty folder called my-ai-project. In VS Code, choose File → Open Folder and select it.

You can trust this empty folder if asked. It stays on your laptop; no GitHub repository is needed.

Review the changes, then open README.md to check the result.

Need help?

Where are my course exercises?

This page covers installation only. Return to your course page for its exercise download. AI at university uses the lesson 4 ai-practice folder; the PhD workshop uses ai-workshop.

Not a student, or still waiting for approval?

You can use Copilot Free with a limited allowance, or an existing Copilot plan. Skip the Education application if it does not apply to you. If you are waiting, activate Student access after approval.

My Education application is stuck.

Check your application status for requests for evidence. A dated student card, transcript or enrolment letter may help. If your institution does not issue an email address, follow GitHub's guidance. See the Education troubleshooting guide for other problems.

I am approved, but Copilot still says Free.

Education approval and Copilot activation are separate. In Education benefits, find Free GitHub developer resources for students and teachers, choose Learn more, then activate Copilot Student. If access still has not appeared after several days, contact GitHub Support.

I signed in with the wrong account.

In VS Code's Accounts menu, sign out of the wrong GitHub account and sign in with your Education account. Check which account your browser is using too.

Is this the university's Microsoft Copilot?

No. GitHub Copilot works on project files in VS Code. Microsoft Copilot is a separate service; your university Microsoft sign-in does not activate GitHub Copilot.

Do I need anything else?

This first task needs no API key, terminal commands or extra software. Running Python, R or LaTeX later needs the relevant software; follow your course instructions when needed.

Practise with public or invented material. Before adding real research files, check your institution's rules and the data's permissions.
