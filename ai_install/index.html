01

Your student access

Sign up for GitHub Education

GitHub Education verifies your student status. Apply as soon as your school or university email is available; approval and benefit activation can take several days.

  1. Create a GitHub account, or sign in to the one you already use.
  2. Add your school or university email address in Settings → Emails and verify it. If your institution does not issue one, follow GitHub's guidance on supporting documents.
  3. Open Education benefits, choose Start an application, and apply as a student.
  4. Follow the application prompts. If asked, provide proof of current enrolment, such as a dated student card, transcript or enrolment letter.
Apply for GitHub Education ↗

Already applied? Continue with the VS Code and folder steps while you wait. Come back to step 2 after approval.

02

After Education approval

Activate GitHub Copilot

Copilot is the AI assistant inside VS Code. Education approval and Copilot activation are separate steps.

  1. Return to your Education benefits.
  2. Find the Copilot benefit. Under Free GitHub developer resources for students and teachers, choose Learn more and follow the activation prompts.
  3. Check your Copilot settings to confirm that the Copilot Student plan is active.
Check Copilot access ↗

Only seeing paid options? Do not buy a plan for this setup. Student benefits can take several days to appear after verification. Wait and retry; see the help below if the problem continues.

Not using student benefits? Check that your existing plan or Copilot Free is active instead. The Student and Free plans have usage limits and automatic model selection.

03

Your workspace

Download Visual Studio Code

VS Code is the app where you will open your project folder, work on files and talk to Copilot.

Download VS Code ↗
On Windows

Download the Windows installer. Run it, follow the installation prompts, then open Visual Studio Code from the Start menu.

On Mac

Download the Mac version and open the downloaded archive. Move Visual Studio Code to Applications, then open it.

Choose Visual Studio Code. You do not need the separate Visual Studio product, a command-line AI tool or an API key for this setup.

04

Use the same GitHub account

Connect Copilot to VS Code

  1. Open VS Code and find the Copilot icon in the status bar.
  2. Choose Use AI Features or Sign in to use Copilot.
  3. Choose GitHub and finish signing in through your browser. Use the same GitHub account that has your Copilot access.
  4. Allow the browser to return you to VS Code. Open the Copilot chat panel.
Cannot find Copilot?

Open the Accounts menu in VS Code and look for Sign in with GitHub to use GitHub Copilot. Update VS Code if the option is missing, then follow the official setup guide.

Education still pending? An eligible account can use Copilot Free while waiting. Return to step 2 to activate Student access after approval.

Microsoft Copilot is a separate service. This sign-in connects GitHub Copilot to VS Code.

05

Keep everything together

Open a project folder

Start with an empty folder for your first project.

  1. In Documents, create a new folder called my-ai-project.
  2. In VS Code, choose File → Open Folder and select my-ai-project.
  3. If VS Code asks about workspace trust, you can trust this empty folder you have just created.

Keep this folder on your laptop. You do not need to create a GitHub repository.

06

Try an agent

Ask Copilot to create a file

Open Copilot chat, choose Agent and send this prompt:

Your first task

Create a README.md file in this folder with the heading "My first AI project" and three bullet points explaining what you can help me do. Do not change any other files.

Review the proposed changes. Open README.md in the file list and check the result.

If you get stuck

A few common questions

My student application has not been approved.

Complete the VS Code and folder steps while you wait. Check your Education application status and any requests for further evidence. Use GitHub's Education troubleshooting guide if the application is rejected or stalled.

I am verified, but Copilot still says Free.

Approval and activation are separate. Return to step 2 and try the activation prompts. Benefits can take several days to apply. If Student access is still unavailable after that, contact GitHub Support. Do not purchase a subscription to fix this.

I have signed in with the wrong account.

In VS Code, open Accounts, sign out of the incorrect GitHub account, and sign in again with your Education account. Check which account your browser is using as well.

Can I use the university's Microsoft Copilot?

Yes, for questions and learning. These instructions set up a separate tool, GitHub Copilot, for working with project files in VS Code. Your university Microsoft sign-in does not activate GitHub Copilot.

My laptop will not let me install VS Code.

If it is managed by your school or employer, check its software portal or ask IT for help installing VS Code.

Should I add my own research data?

Use public or synthetic material for this setup. Before using real research files with AI, check your university's rules and the data's permissions. Keep personal, confidential and restricted data out of the practice folder.

For more help, use the VS Code setup guide or GitHub Support.
