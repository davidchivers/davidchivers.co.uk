MAKE YOUR OWN

Three steps to a first draft

  1. 01

    Put everything in one folder

    Download and unzip the Durham skill. Put it beside a copy of your PowerPoint, Beamer file or lecture outline. Open that folder in your AI assistant.

  2. 02

    Ask the assistant to build the slides

    Copy the prompt below and tell it which file to use. It will check the software it needs, create the slides and open them for you.

  3. 03

    Review, then ask for changes

    “Make slide 4 clearer.” “Add a worked example.” Keep the whole project folder for future edits. Share the finished HTML presentation: students open it in a browser.

A prompt to get started

Read durham-quarto-slides/SKILL.md and use it to turn my slides or outline into a Quarto presentation. Help me set up Quarto and Python 3 if needed. Use the light-touch conversion: keep my content and order, apply the Durham design and include the Edit slides button. Check that nothing was lost, the layout works and edits save. Give me the editable project and HTML presentation, then open it for review.

What gets checked? Can I ask for a fuller review?

DEFAULT

Light-touch conversion

Preserve the content, use the Durham layout and tidy equation styling, spacing and obvious typos. Check that the slides render, retain their content and save correctly.

OPTIONAL

Full check

Ask for independent calculation and derivation checks, all links, every-slide visual review and deeper accessibility checks. This takes extra time; request it for the whole deck or just a particular issue.

Any maths introduced or materially changed is checked in either mode. A light-touch conversion does not independently verify every result in the original slides. Teaching and animation suggestions are also available when requested.

WHEN YOU WANT TO CHANGE SOMETHING

How do I edit my slides?

Usually, just ask the AI

Open your course project folder in the assistant and describe the change. Use this for wording, maths, graphs and layout.

“Shorten slide 3 and add a simple example after it. Keep the rest of the wording and design. Rebuild the slides and show me.”

If you only have the finished HTML, give it to the assistant and explain what you want changed.

For a quick text correction

  1. Click Edit slides at the top-right of the presentation.
  2. Click the outlined text and make your change.
  3. Click Save updated slides and keep the downloaded HTML.

The button works both online and in the downloaded HTML. Typing alone does not save your changes. The download is your edited copy; the website and original project stay as they were.

Try editing the example ↗

Presenting and keeping edits for next time

Preview / present returns to the normal view. The edit button hides in fullscreen (press F) and when printing. Exit fullscreen to edit, or use Alt+Shift+E.

Before asking AI to rebuild the deck, give it your edited HTML and project folder. Say: “Import these staff edits into my project, then rebuild.”

FIRST TIME USING A SKILL?

A little help getting started

Start with these three steps. Open the extra help only when you need it.

  1. 01

    Download and unpack

    Put the unpacked skill and a copy of your slides in one course folder.

  2. 02

    Ask your assistant

    Open that folder in your AI assistant, paste the starter prompt and tell it which slides to use.

  3. 03

    Review and keep

    Ask for any changes, share the finished HTML and keep the whole project folder for next time.

More help: downloads and setup

On Windows, right-click the ZIP and choose Extract All; on a Mac, double-click it. Keep the entire durham-quarto-slides folder together. It contains SKILL.md, the instructions your assistant reads.

Use Codex, Claude Code or VS Code with GitHub Copilot in Agent mode. The starter prompt asks your assistant to check Quarto and Python 3 and help with missing setup. Include separate figures or data alongside your slides.

Already have the skill? Ask your assistant to update it from the current ZIP while preserving your course files.

More help: editing and saving

Tell the assistant the slide number and the change you want: “Spread out the text on slide 4” or “Keep this equation in the same style as slide 3”. It should repair lost content or conversion errors as part of the first pass.

For a small text correction, click Edit slides in the presentation's top-right corner, online or in your downloaded HTML. Use Undo edit or Edit link as needed, then Save updated slides. Keep the newly downloaded copy. Ask the assistant to change maths, images or layout.

Anyone with the HTML can edit their own copy. Before the assistant rebuilds your master project, give it that edited HTML and ask: “Import these staff edits into my project, then rebuild.” Older HTML copies need downloading again to get the new button.

Optional: request a full check

A full check uses extra time to review the original maths, links, layout and accessibility. You can also ask for a narrower check, such as the maths on three slides.

A prompt for the optional full check

Use the Durham slide skill to run a full check of this deck. Check calculations and derivations, links, slide layouts and accessibility. Repair clear errors while preserving the teaching content. Summarise material changes and say which checks could not be completed. Keep new teaching or animation suggestions separate.
