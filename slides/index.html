MAKE YOUR OWN

Three steps to a first draft

  1. 01

    Put everything in one folder

    Download and unzip the Durham skill. Put it in a folder with your PowerPoint, Beamer file or lecture outline. Open that folder in your AI assistant.

  2. 02

    Ask the assistant to build the slides

    Use the prompt below. The skill is a set of instructions and a Durham template for the assistant. Ask it to check that Quarto and Python 3 are available, then create and open the presentation.

  3. 03

    Look at the slides and ask for changes

    “Make slide 4 clearer.” “Add a worked example.” “Keep this graph in the same position.” Check the result, then share the finished HTML file. Keep the whole editable project folder for future changes. Students only need a browser.

A prompt to get started

Read durham-quarto-slides/SKILL.md in this folder and use it to turn my slides or outline into a Quarto presentation. Check that Quarto and Python 3 are available; help me set them up if needed. Use the light-touch conversion: preserve the teaching content and order, apply the Durham template, make equation formatting and spacing consistent, and include the Edit slides button. Check conversion fidelity, layout and saving. Give me the editable project and an HTML presentation, then open the slides for me to review. Leave the full maths and external-link audit as an optional next step.

Choose how much checking you want

DEFAULT

Light-touch conversion

Preserve the content, use the Durham layout and tidy equation styling, spacing and obvious typos. Check that the slides render, retain their content and save correctly.

OPTIONAL

Full check

Ask for independent calculation and derivation checks, all links, every-slide visual review and deeper accessibility checks. This takes extra time; request it for the whole deck or just a particular issue.

Any maths introduced or materially changed is checked in either mode. A light-touch conversion does not independently verify every result in the original slides. Teaching and animation suggestions are also available when requested.

WHEN YOU WANT TO CHANGE SOMETHING

How do I edit my slides?

Usually, just ask the AI

Give the assistant your editable project folder and describe the change. It can rewrite a slide, add an example, update a graph or change the layout.

“Use the Durham slide skill. In this deck, shorten slide 3 and add a simple example after it. Keep the rest of the wording and design. Rebuild the slides and show me.”

Keep the source file, images and companion files together. If you only have the finished HTML, give it to the assistant and explain what you want changed.

For a quick text correction

Click Edit slides in the top-right corner of the presentation, or try the editor here ↗. Click outlined text, make your change, then choose Save updated slides. Preview / present returns to the normal view.

This downloads a complete edited HTML copy. Keep the download: typing in the browser alone does not save your changes. Anyone with the file can edit their own copy; they cannot change this website or your master project through that button.

The small button is visible in the normal browser view. It disappears in presentation fullscreen (press F) and when printing. Exit fullscreen to edit again; Alt+Shift+E remains an alternative shortcut.

Use AI for changes to maths, graphs and layout. To keep a browser correction in your master project, give the edited HTML back to the assistant and say: “Import these staff edits into my project, then rebuild.”

FIRST TIME USING A SKILL?

A little help getting started

A skill is a folder of instructions and reusable files for your AI assistant. You describe what you want; the assistant uses the skill to build the slides.

Show the step-by-step guide
  1. 01

    Create a folder for your course

    Make a folder somewhere you can find again, such as Documents. Put a copy of your PowerPoint, Beamer source or lecture outline inside it. Include any separate images or data that the slides use. Keep your original files.

  2. 02

    Download and unpack the skill

    Download the Durham skill ZIP. On Windows, right-click it and choose Extract All; on a Mac, double-click it. Put the unpacked durham-quarto-slides folder inside your course folder. Keep the whole folder, including its templates and scripts, together.

    You should be able to open durham-quarto-slides and see a file called SKILL.md. You do not need to edit that file.

  3. 03

    Open the course folder in your assistant

    Use Codex, Claude Code, or VS Code with GitHub Copilot in Agent mode. Give it access to this course folder. Copy the starter prompt above into its chat and tell it which presentation to use.

    The assistant needs Quarto and Python 3 to build the slides. The prompt asks it to check these and help with any missing setup. Opening a finished HTML presentation only needs a browser.

  4. 04

    Review the first version

    The starter prompt asks for a light-touch conversion. Look through the result, including equations, figures and crowded slides. Ask for concrete changes: “Spread out the text on slide 4”, “Keep this equation in the same style as slide 3”, or “Preserve the wording but give the graph more room”.

    If something was lost or looks wrong, give the assistant the slide number and explain the difference. It should repair conversion errors without needing a separate full review.

  5. 05

    Make a small text change yourself

    Open the HTML and click Edit slides in the top-right corner. Click the outlined words, type your correction and use Undo edit if needed. For a link, click its words and choose Edit link.

    Choose Save updated slides, then open the newly downloaded HTML to check it. Use Preview / present to close the editing toolbar. Maths, images and layout are protected; ask the assistant to change those.

  6. 06

    Keep the project and share the presentation

    Keep the entire editable project folder for next time. Share the finished HTML with colleagues or students, who can open it in a browser. If you made browser edits, share the newly saved copy.

    To keep those edits when the assistant next rebuilds the slides, give it both the edited HTML and the project folder. Ask: “Import these staff edits into the master project, rebuild it and show me the result.” Saving a browser copy does not automatically update a website.

  7. 07

    Ask for a full check when you want one

    This is an optional second pass. It checks more of the original material and uses extra time. You can also ask for a narrower check, such as the maths on three particular slides.

    A prompt for the optional full check

    Use the Durham slide skill to run a full check of this deck. Independently check calculations and derivations, reconcile equations with figures and explanations, check all links, review every slide's layout and run the available accessibility checks. Repair clear errors while preserving the teaching content. Summarise material changes and say which checks could not be completed. Keep new teaching or animation suggestions separate.

Already have an older copy of the skill? Download the current ZIP and ask your assistant to update its installed copy while preserving your course files. The download on this page includes the light-touch default and the visible Edit slides button.
