What is Quarto? What is the skill?

Quarto turns text, equations, images and code into a presentation you open in a browser.

The Durham skill gives your AI assistant the template, logo and instructions to create these slides from your PowerPoint, Beamer file or outline. You do not need to write code.

See the source and more Quarto examples

The editable source is a .qmd file. A heading starts a slide; Quarto builds the HTML presentation you share.

How do I install and use the skill?

  1. Download and unpack

    Unzip the Durham skill. Put the whole durham-quarto-slides folder beside a copy of your slides in one course folder.

  2. Ask your assistant

    Open the course folder in Codex, Claude Code or VS Code with GitHub Copilot. Paste the prompt below and tell it which slides to use.

  3. Review and keep

    Ask for any changes. Keep the project folder for future edits and share the finished HTML presentation, which opens in a browser.

A prompt to get started

Read durham-quarto-slides/SKILL.md and use it to turn my slides or outline into a Quarto presentation. Help me set up Quarto and any dependencies this deck needs. Use the light-touch conversion: keep my content and order, apply the Durham design and leave browser editing off. Check that nothing was lost, the layout works and the presentation opens and navigates correctly. Give me the editable project and HTML presentation, then open it for review.

Help with folders and installation

On Windows, right-click the ZIP and choose Extract All; on a Mac, double-click it. Keep all the skill's files together, including SKILL.md. Include any separate figures or data with your slides.

The assistant needs Quarto to build slides. Some decks also need Python or other dependencies; the prompt asks it to check and help with setup. Viewing the finished HTML only needs a browser.

For repeat use, ask your assistant to install the skill in the project. It can use .agents/skills/ for Codex, .claude/skills/ for Claude Code or .github/skills/ for GitHub Copilot. For a first try, asking it to read the unpacked SKILL.md is enough.

Already have an older skill? Ask the assistant to update it from the current ZIP while preserving your course files.

  • Claude Code: start in the course folder and paste the same prompt. Skills guide

This pack was tested with Codex. Claude Code and GitHub Copilot support skills too, but this pack has not been tested in every assistant. The assistant needs access to your folder and permission to run Quarto.

How do I edit and save slides?

Ask the assistant

Open your course project and describe the change: “Shorten slide 3” or “Give the graph on slide 4 more room”. Use this for wording, maths, images and layout. If you only have the HTML, give it that file.

Keep one current version

Ask the assistant to save your changes in the editable project, rebuild the HTML and publish it at the same online address. Your Blackboard link can stay in place.

Published slides have no edit button by default. Keep the source project for later changes, or use PowerPoint if you prefer editing visually.

Optional: edit a downloaded copy in the browser

Ask the assistant to enable the optional local-copy editor if you need it. Its Edit local copy button lets anyone with that file change simple text; Download edited copy saves a new HTML file. It does not update GitHub, Blackboard or the shared website.

Give the saved HTML back to the assistant to incorporate the changes into your project and republish them. This option is for a separate working copy; the student presentation stays free of editing controls.

How do I share and update slides on Blackboard?

Keep one online copy and put its permanent link in Blackboard. Ask the AI to publish updates to that same address, so you do not need to replace the course link each time.

  1. Choose where the slides live

    For interactive browser slides, use a website such as GitHub Pages, if the material is suitable for public access. Ask the AI to publish the finished presentation and check that it opens. Use the website address, rather than the GitHub file-preview page.

  2. Ask the AI to add the Blackboard link

    Tell it the course and academic year, folder, exact title and where the link belongs. It can use Create → Link → Web Link, enter the address and select Open in a new window. Keep it Hidden from students while you review, then ask to release it when ready.

  3. Update the same online copy

    Ask for changes in the source project, then a rebuild and publication at the same address. Have the AI check the live presentation and the saved Blackboard link. Keep the existing title, position and visibility unless you want them changed.

A prompt to publish and add the link

Use the Durham slide skill to publish these slides and add their permanent link to Blackboard. Use my existing hosting destination if there is one; otherwise help me choose GitHub Pages for public interactive HTML or OneDrive for shared files. Establish whether the material may be public before uploading it. Use this course and academic year: [course/year], this folder: [folder], this exact title: [title], and put the link below [existing item]. Open it in a new window and keep it hidden from students for review. Check the live file, link destination, placement and visibility, and tell me if student access could not be verified. Keep browser editing off. For later updates, replace the content at the same address and leave the Blackboard link in place.

Can I use OneDrive instead?

Yes, for a shared PowerPoint, PDF or downloadable file. Ask the AI to upload or update the file in your university OneDrive, obtain a view link for the intended students and put that link in Blackboard. Keep the same file and sharing link when updating, and check access afterwards.

An HTML file preview is not the same as a working interactive presentation. Ask the AI to test the actual opening behaviour; use a web host for the browser-slide experience, or clearly label a file that students need to download. Microsoft's file-preview guide lists supported formats.

Access, hidden links and sign-in

A hidden Blackboard link is not visible to students in the course, but its public web destination is still accessible to anyone with the address. Keeping a public page out of navigation and search results does not make it private. Use university-controlled sharing for material that requires restricted access.

The AI needs access to your files, hosting account and Blackboard to complete the steps. You may need to sign in or complete university MFA yourself. If access is unavailable, ask it to prepare the files and exact link and show you the remaining steps. A successful check in a staff account does not prove student access.

What checks are included?

Light-touch conversion by default

Keep your content and order, apply the Durham layout, and tidy equation styling, spacing and obvious typos. Check that content is retained, the slides render, open and navigate correctly. Conversion errors are repaired as part of this pass.

A full check when you request it

Ask for independent calculation and derivation checks, links, every slide's layout and deeper accessibility checks. This takes extra time; you can request it for the whole deck or a particular issue.

Optional PDF and PowerPoint downloads

During a full review, the assistant will offer a downloadable PDF, PowerPoint, both, or neither. Generating and checking these files can take a while, especially for long decks or several lectures. It will wait for your choice before creating them.

PowerPoint can use editable objects or slide images that preserve the appearance; ask the assistant to explain the tradeoff. Static downloads do not include the web slides' interactive features. If wanted, ask for a small Download menu in the online slides.

Any maths introduced or materially changed is checked in either mode. A light-touch conversion does not independently verify every result in the original slides. Teaching and animation suggestions are available on request.
