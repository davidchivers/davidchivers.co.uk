MAKE YOUR OWN

Three steps to a first draft

  1. 01

    Put everything in one folder

    Download and unzip the Durham skill. Put it in a folder with your PowerPoint, Beamer file or lecture outline. Open that folder in your AI assistant.

  2. 02

    Ask the assistant to build the slides

    Use the prompt below. The skill is a set of instructions and a Durham template for the assistant. Ask it to check that Quarto and Python 3 are available, then create and open the presentation.

  3. 03

    Look at the slides and ask for changes

    “Make slide 4 clearer.” “Add a worked example.” “Keep this graph in the same position.” Check the result, then share the finished HTML file. Keep the whole editable project folder for future changes. Students only need a browser.

A prompt to get started

Read durham-quarto-slides/SKILL.md in this folder and use it to turn my slides or outline into a Quarto presentation. Check that Quarto and Python 3 are available; help me set them up if needed. Use the Durham template, preserve the teaching content and include the built-in text editor. Give me the editable project and an HTML presentation. Check the maths, layout, figures and links, then open the slides for me to review.

Which AI assistant?

Use an assistant that can read and change files in your folder and run Quarto. These are the relevant options:

Codex

Open your course folder in Codex, then use the prompt above. It can read the unpacked skill, edit your project and build the HTML.

Claude Code

Start Claude Code in your course folder and use the same prompt. Give it access to the skill, your slides and the Quarto tools.

GitHub Copilot

Yes: open the folder in VS Code and choose Agent in Copilot Chat. Ask it to read the skill and build the slides. This is GitHub Copilot, rather than the university's Microsoft Copilot chat.

Optional: install the skill so the assistant can find it again

Ask your assistant to put the unpacked durham-quarto-slides folder in the project's skill location. Keep all its files together.

  • Codex: .agents/skills/
  • Claude Code: .claude/skills/
  • GitHub Copilot in VS Code: .github/skills/

Then ask it to use the durham-quarto-slides skill. For a first try, simply asking it to read the unpacked SKILL.md is enough.

The example was built and checked using Codex. Claude Code and GitHub Copilot support this skill format; this particular package has not been tested in every assistant. A normal chat with an uploaded file may help with wording, but needs a suitable working environment to build and check the slides.

WHEN YOU WANT TO CHANGE SOMETHING

How do I edit my slides?

Usually, just ask the AI

Give the assistant your editable project folder and describe the change. It can rewrite a slide, add an example, update a graph or change the layout.

“Use the Durham slide skill. In this deck, shorten slide 3 and add a simple example after it. Keep the rest of the wording and design. Rebuild the slides and show me.”

Keep the source file, images and companion files together. If you only have the finished HTML, give it to the assistant and explain what you want changed.

For a quick text correction

Try the built-in editor ↗, or press Alt+Shift+E in the presentation. Click outlined text, make your change, then choose Save updated slides.

This downloads a complete edited HTML copy. It does not update this website. Keep the download: typing in the browser alone does not save your changes.

Use AI for changes to maths, graphs and layout. To keep a browser correction in your master project, give the edited HTML back to the assistant and say: “Import these staff edits into my project, then rebuild.”
